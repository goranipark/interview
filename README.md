# 공공기관 주민자치 탐구 면담실

초등 4학년 2학기 사회 "지역의 공공기관과 주민 참여" 단원 학습용 웹앱입니다.
학생이 '어린이 탐구 기자'가 되어 7개 공공기관 담당관과 채팅으로 면담하고,
학습지를 작성하고, 퀴즈를 풀고, 기자증과 보고서를 발급받습니다.

- 인터넷 연결 **불필요** (외부 AI API를 쓰지 않습니다)
- 서버·데이터베이스 **불필요**
- 학생에게는 **파일 하나(index.html)** 만 주면 됩니다

---

## 1. 선생님이 수정·확인할 때 (개발 모드)

내용을 고치거나 화면을 확인할 때 씁니다.

1. `setup.bat` 더블클릭
2. 검은 창에 `http://localhost:5173` 이 뜨면, 브라우저 주소창에 그 주소를 입력
3. 파일을 고치면 화면이 **자동으로 새로고침**됩니다
4. 끝낼 때는 검은 창을 닫으면 됩니다

> Mac·Linux는 터미널에서 `./setup.sh`

**처음 한 번만** Node.js가 필요합니다. 없으면 스크립트가 안내하고 멈춥니다 →
[nodejs.org](https://nodejs.org) 에서 LTS 버전 설치.

---

## 2. 학생에게 나눠줄 파일 만들기 (배포용)

1. `build.bat` 더블클릭
2. 끝나면 `dist` 폴더가 자동으로 열립니다
3. 그 안의 **`index.html` 파일 하나**가 완성품입니다

이 파일은 JS·CSS가 전부 안에 들어 있는 **단일 파일**이라,
USB에 복사해서 **더블클릭만 하면** 인터넷 없이 바로 실행됩니다.

> 파일을 쪼개서 빌드하면 브라우저 보안 정책(CORS) 때문에
> 더블클릭으로 열었을 때 빈 화면이 나옵니다. 그래서 단일 파일로 만듭니다.

---

## 3. 배포 방법 3가지

| 방법 | 어떻게 | 장점 | 주의할 점 |
|---|---|---|---|
| **학교 PC에 복사** | `index.html`을 각 PC 바탕화면에 복사 | 인터넷 불필요, 가장 단순 | PC마다 복사해야 함 |
| **USB 배포** | USB에 `index.html` 하나만 넣어 돌리기 | 학생 개인 기기에서도 실행 | 학생이 파일을 지우지 않게 안내 |
| **GitHub Pages** | 아래 주소로 링크 공유 | 링크 하나로 어디서든 접속 | 인터넷 필요 |

### GitHub Pages 주소

https://goranipark.github.io/interview/

`main` 브랜치에 푸시하면 GitHub Actions가 **자동으로 빌드해서 위 주소에 배포**합니다.
(`.github/workflows/deploy.yml`) 따로 `build.bat`을 돌리거나 `dist`를 커밋할 필요가 없습니다.

- 배포 진행 상황: 저장소 상단 **Actions** 탭에서 확인 (보통 1~2분)
- 초록 체크(✅)가 뜨면 반영 완료. 학생들에게는 위 주소만 알려주면 됩니다.
- 브라우저에 예전 화면이 남아 있으면 **Ctrl+F5** 로 새로고침하세요.

### 학생 진행 상황 저장에 대해

학생이 입력한 이름·스크랩·소감·퀴즈 답안은 **그 학생이 쓰는 브라우저에** 저장됩니다.

- 새로고침하거나 브라우저를 껐다 켜도 이어서 할 수 있습니다
- 단, **다른 PC로 옮기면 이어지지 않습니다** (서버에 저장하지 않으므로)
- 다음 반 학생이 쓰기 전에는 브라우저에서 "인터넷 사용 기록 삭제"를 하거나,
  각 기관의 `↺ 대화 다시 시작` / 퀴즈의 `↺ 다시 풀기` 를 누르면 됩니다

### 결과물 제출

④ 탭의 **`🖨 기자증 · 보고서 인쇄하기`** 를 누르면 기자증과 보고서만 인쇄됩니다.
인쇄 창에서 대상을 **「PDF로 저장」** 으로 바꾸면 파일로 제출할 수도 있습니다.
(기자증의 파란 배경까지 나오게 하려면 인쇄 창의 **「배경 그래픽」** 옵션을 켜세요.)

## 4. 내용 수정하기

| 고치고 싶은 것 | 파일 |
|---|---|
| 담당관 인사말, 질문·답변(기관당 15개), 추천 질문 | `src/data/institutions.js` |
| 퀴즈 문제(14개), 기관 한 줄 요약 | `src/data/quiz.js` |
| 색상·글자 크기 | `src/styles/tokens.css` |
| 답변을 못 알아들었을 때 나오는 문구 | `src/data/institutions.js` 의 `FALLBACK_MESSAGES` |

답변 데이터를 고칠 때는 `keywords` 배열에 **학생이 실제로 칠 법한 낱말**을 넣어 주세요.
예: `keywords: ["소화기", "사용법"]` → "소화기 어떻게 써요?" 같은 질문에 이 답이 나옵니다.

수정한 뒤에는 `build.bat`을 다시 돌려 새 `index.html`을 만들어야 학생 파일에 반영됩니다.

## 5. 폴더 구조

```
interview/
├─ concept.md / design.md / data.md / todo.md   기획·설계 문서
├─ setup.bat, setup.sh      개발 모드 실행
├─ build.bat                학생 배포용 파일 만들기
├─ dist/index.html          ★ 학생에게 주는 완성 파일
└─ src/
   ├─ App.jsx               탭 전환
   ├─ data/                 기관·Q&A·퀴즈 데이터
   ├─ utils/matchAnswer.js  질문 키워드 매칭 엔진
   ├─ state/                전역 상태 + 저장
   ├─ styles/               색상 토큰 및 화면별 스타일
   └─ components/
      ├─ Header.jsx
      ├─ tab1-interview/    면담하기
      ├─ tab2-worksheet/    학습지 작성
      ├─ tab3-quiz/         개념 정리 & 퀴즈
      └─ tab4-report/       기자증 & 보고서
```
